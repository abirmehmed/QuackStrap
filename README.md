# 🦆 QuackStrap

QuackTrack — Bootstrap Edition. A duck-farm management dashboard for my
Khaki Campbell flock (34 layers + 11 upcoming), built as a Bootstrap 5
component showcase wired to a live Express API.

## What's inside

- 🥚 Eggs — daily egg log
- 💰 Expenses — feed & medicine costs
- 💵 Sales — income tracking
- 📊 Stats — lay rate, 7-day average, monthly profit
- 📈 Egg rhythm — last-7-days bar chart
- 🏡 Farm at a glance — flock, feed estimate, daily routine

Bootstrap components demonstrated: navbar + dropdown, carousel, cards,
table + form, nav-pills, accordion, modal, flex & 12-col grid.

## Run locally

Kitchen first:

    git clone https://github.com/abirmehmed/Ducky-Api.git
    cd Ducky-Api && npm install && node server.js   # :4001

Then this cockpit:

    open index.html

## Stack

Bootstrap 5 + vanilla JS · Express + JSON-file API
